# Lessons that fail today because of a compiler or standard-library problem,
# one per line as `Name: reason`. bin/jux/tests/rux_lessons.rs accepts these
# failures and fails the moment a listed lesson passes, so remove the line in
# the same commit that fixes the bug. The README has a minimal repro for each.

Algorithm: a nullable narrowed inside a ternary branch leaks E0308 when interpolated
Math: GAP, the Rust f64 methods (powf, ln, log2, log10, exp, sin, cos, tan, hypot, trunc, min, max) are not reachable on `double` (E0413)
Propagate: `switch` on a Result with `case Ok(var v)` / `case Err(var e)` lowers to std::result::Result and leaks rustc E0308 against jux.std Result
Result: same Result-switch lowering leak as Propagate; the inner switch on the bound error then also loses its enum path (E0531)
Slice: record static call `Span.of(...)` leaks E0423; a user method named `length()` is rewritten to the `.len() as isize` intrinsic (E0214); indexing an array component inside a record leaks E0608
