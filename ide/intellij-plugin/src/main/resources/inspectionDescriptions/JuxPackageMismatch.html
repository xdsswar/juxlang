Reports a package declaration that does not match the file's location under its package root, or a missing one where the location implies a package. A file in src/com/example/ declares package com.example;, and a file directly in src/ declares none.

The package root is a directory marked Jux Sources Root or Jux Test Sources Root, or, with nothing marked, the src/ and test/ directories of a jux.toml project. A test file may also add .test to its package. Files outside a package root are not checked.

Quick-fixes: set the package name to match the location, move the file to the directory of its declared package, or add the missing declaration.
