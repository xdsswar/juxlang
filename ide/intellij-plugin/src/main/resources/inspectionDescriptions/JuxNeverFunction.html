Reports a function declared to return never that can reach the end of its body (E0485) or contains a return (E0486).

A never function does not return: every path throws, loops forever, or calls another never function. In return, a call to one ends its path the way a throw does, so the code after it needs no dummy return. A return inside a lambda or an anonymous class belongs to that and is fine.

Quick-fix: end the body with a throw.
