Reports x == null or x != null where x is declared with a type that cannot hold null.

A Jux type is non-null unless it says ?, so the test always gives the same answer:

void greet(String name) {
    if (name != null) { ... }   // always true: 'name' is not nullable
}

Quick-fix: replace the test with its answer, then fold the branch with the constant-condition fix.
