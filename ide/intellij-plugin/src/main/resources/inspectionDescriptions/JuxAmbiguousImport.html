Reports a simple type name that two wildcard imports bring in for different types, where it is used: in a type, a new or a static access (E0303). Nothing written says which one is meant, so the compiler does not pick one.

Importing both packages is fine as long as the name is not used. A declaration of the file, a type of its own package or a single-type import of the name settles it. The quick-fixes import the candidate you mean by name.

Also reports two single-type imports that bind one simple name to different types. Two spellings of one type (a crate family's nested alias beside the host's type) are one import.
