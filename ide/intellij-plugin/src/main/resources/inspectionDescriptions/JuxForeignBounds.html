Reports a call to a foreign method whose bound on its own type argument is not met (E0446).

A generated .jux.d stub carries a foreign method's bounds as @RustBounds("T: Ord"). What each Rust trait asks of a Jux type is the operator rule the backend follows: Ord and PartialOrd are operator<=>, Hash is operator hash.

So people.sort() on a Vec<Person> is reported when Person declares no operator<=>. Declare one, or pass a comparator where the method takes one: people.sort_by((a, b) -> a.age <=> b.age).

A floating-point element meets PartialOrd but not Ord (NaN compares with nothing), and an array or a collection element meets neither: both are shared handles whose contents change under them. A type parameter is checked where it is instantiated, so it is never reported here.
