Reports the errors a type alias itself can carry:
  • an alias that stands for itself through other aliases, type A = B; type B = A; (E0498);
  • a use of a generic alias with the wrong number of type arguments, Dict<String, int> for type Dict<V> = HashMap<String, V>; (E0443). A use with no type arguments is left to inference.
Everywhere else an alias is read as the type it stands for.
