Reports jux.toml workspace problems the build would also stop at or warn about (JUX-BUILD-SYSTEM-ADDENDUM §B.7):
  • a key in [workspace] other than members, exclude and default-members;
  • a members entry whose directory does not exist or holds no jux.toml, and a pattern (tools/*) that matches no package;
  • a default-members entry that is not a workspace member;
  • a key.workspace = true (or { workspace = true }) entry whose key the workspace root's [workspace.package] or [workspace.dependencies] does not declare, or that has no workspace root above it.

Example:

[package]
name = "app"
license.workspace = true   # the root declares no [workspace.package] license
