Reports a Jux class, interface, record or enum written with the wrong number of type arguments, at any depth of nesting (E0443): Vec<Vec<Pair<int>>> for a Pair<K, V> is reported at the inner Pair<int>, in a field, a parameter, a return, a local, a new, a supertype or a bound. A Rust type may leave defaulted parameters unwritten, and a type written with no arguments is left to inference.
