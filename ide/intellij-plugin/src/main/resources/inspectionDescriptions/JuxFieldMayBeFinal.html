Reports a private field that is only set while the object is being built.

A field with an initializer that nothing assigns afterwards, or one that each constructor assigns exactly once, can be declared final, which says so and lets the compiler hold you to it.

class Account {
    private String owner;          // Field 'owner' may be 'final'
    Account(String owner) { this.owner = owner; }
}

Quick-fix: add final.
