Reports a condition whose value is always the same: if (true), while (false), false ? a : b, a value compared with itself (n == n), or two literals compared (1 < 2).

while (true) and do ... while (false) are idioms and are not reported. Comparing a value with itself is only reported for a primitive whose == is reflexive: never a float, since x != x is how a NaN test is written, and never a class, whose operator== may say anything.

Quick-fix: keep only what always happens.
