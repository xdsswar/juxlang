Reports an if statement whose branches only return, or only assign, true and false.

The statement is its condition:

if (n > 0) return true; else return false;   // return n > 0;
if (done) { return false; } return true;      // return !done;
if (ok) flag = true; else flag = false;       // flag = ok;

Quick-fix: replace the statement with the simpler form.
