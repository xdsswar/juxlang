Reports a member of a T? value used with . when nothing in the function checks the value.

A nullable value can be used as its type only after a check (Type system §T.6):

void show(String? label) {
    print(label.len());        // 'label' may be null: check it first
}

Check it (if (label != null), label ?: "none", label?.len()), or, when you know better, use the quick-fix, which asserts it with !!.
