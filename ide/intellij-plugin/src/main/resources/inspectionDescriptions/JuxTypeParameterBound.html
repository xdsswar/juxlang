Reports a type parameter bound the compiler refuses (type system §T.4.6):
  • a bound no other type can meet: a Rust type, a record, an enum, a primitive or String, as in <V extends Vec<int>>, or an array or nullable type, <T extends int[]>, <T extends Named?> (E0459). Such a bound admits only that one type, so write the type where the parameter is used, or bound the parameter by an interface. A final Jux class is still a legal bound;
  • an intersection naming two classes, <T extends Animal & Machine> (E0419): a class extends one class, so no type is both. Keep one class and any number of interfaces, in any order (T extends Named & Base is legal).
