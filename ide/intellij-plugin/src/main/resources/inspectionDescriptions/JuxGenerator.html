Reports a yield the compiler rejects, and a generator whose signature or returns break the generator rules.

A generator is a named function or method whose own body contains yield. It returns Iterator<T>, or Stream<T> when it is async.

  • yield in a lambda, a constructor, an operator, an initializer or a switch expression's arm (E0990). A switch arm gives its value as an expression: case 1 -> 10;.
  • return with a value inside a generator (E0994). Quick-fix: yield the value.
  • An interface's default method that yields (E0995).
  • A generator whose return type is not Iterator<T> / Stream<T> (E0996). Quick-fix: change the return type.
  • yield inside an unsafe { } block (E0997).
