Reports a loop that counts an index over a whole sequence and only reads xs[i] with it.

Both counting shapes are recognised, for (int i = 0; i < xs.len(); i++) (or xs.length for an array) and for (var i : 0..xs.len()). The loop is reported only when the index is used for nothing else and the body never assigns xs itself.

Quick-fix: rewrite the loop as for (var x : xs) and each xs[i] as x.
