Reports layout and ABI mistakes the compiler rejects.
  • @align(N) whose argument is not an integer literal or not a power of two (E0519), or that sits on a field, an enum or an interface (E0520).
  • array as T* from a temporary or nested array, or to a pointer to a pointer (E0521).
  • transmute<A, B> without two type arguments, or between primitive types of different sizes (E0522).
  • A free operator declared twice (E0951), or declared only on types no program declares (E0950).
