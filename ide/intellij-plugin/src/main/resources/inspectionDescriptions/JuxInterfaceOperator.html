Reports an operator an interface cannot declare, and an operator without a body outside an interface (E0936).

An interface may require an operator as a contract, T operator+(T other);, and every type that implements the interface declares the operator itself. Such an operator has no body, takes one operand, and is one of + - * / % & | ^ << >>. Equality, ordering, string, indexing and unary operators are declared on the implementing types only.

Quick-fix: remove the body of an interface operator.
