Reports a call to a Java utility class Jux does not have, with the Jux way to write it.
  • Math.abs(x): numbers carry these as methods. Quick-fix: x.abs() (pow becomes powf, log becomes ln).
  • Integer.parseInt(s): Quick-fix: s.parse<int>().
  • Objects.equals(a, b) / Objects.requireNonNull(x): Quick-fix: a == b / x!!.
  • String.valueOf(x): Quick-fix: $"${x}".

A type your program declares under one of these names is not reported.
