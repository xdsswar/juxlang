Reports a ref binding the compiler rejects, and one that adds nothing (E0523, E0524, E0526, W0490, E0702).

ref T is a binding mode, not a type: it gives a value type (String, a primitive, a struct, a record, an enum) the shared reference semantics a class already has. The expression type of a ref T binding stays plain T.

  • E0523: a ref return type (ref int f()) is deferred to a later phase. Return the value, or take a ref parameter and write through it.
  • E0524: ref ref T: one ref already makes the binding shared.
  • E0526: a ref generic argument (Vec<ref int>): a type argument names a type, and ref is a binding mode.
  • W0490: ref on a class, interface, array or collection, which is already a shared reference. Accepted, and means nothing. Quick-fix: remove the keyword.
  • E0702: a ref binding captured by a Worker.spawn closure: the cell is task-local and cannot cross the thread boundary.
