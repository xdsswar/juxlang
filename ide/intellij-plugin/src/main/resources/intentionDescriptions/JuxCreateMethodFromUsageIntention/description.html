Creates the method a call names when the receiver's class does not have it: order.ship(address) adds ship(Address address) to Order.

Parameters come from the arguments, the return type from where the result goes (void for a bare call statement), and the body throws UnsupportedOperationException until it is written. Every guessed type and name is a template stop. Offered only when the class is a project source and all of its supertypes are known, so an inherited method cannot be hiding.
